# امنیت NeoConfig

## اسرار

- `ENCRYPTION_KEY`: کلید AES-256-GCM برای توکن پنل و لینک اشتراک
- `JWT_SECRET`: امضای نشست کاربر
- توکن API پنل: فقط رمزنگاری‌شده در سرور؛ هرگز به مرورگر یا دستور نصب داده نمی‌شود

## SSRF

درخواست‌های واکشی لینک اشتراک:

- فقط `http` / `https`
- بدون نام‌کاربری/رمز در URL
- بررسی DNS و مسدودسازی IPهای خصوصی / لینک‌لوکال / متادیتای ابری
- بدون دنبال‌کردن redirect
- محدودیت زمان و حجم پاسخ

## ایزولاسیون چندمستأجری

کوئری‌های اشتراک، پنل، سرور، برندینگ و audit بر اساس `orgId` / `userId` محدود می‌شوند.

## ایجنت

- توکن enrollment یک‌بارمصرف (هش‌شده)
- سکرت جداگانه برای هر سرور (هش‌شده)
- فقط heartbeat خروجی؛ بدون shell از راه دور
- امکان لغو اعتبارنامه

## لاگ

لینک کامل اشتراک و توکن پنل نباید در لاگ بیاید.
